# Caffinity Café Website

## Files
- index.html — Home
- menu.html — Menu with clickable item-detail modals
- about.html — About / story
- gallery.html — Gallery with lightbox
- contact.html — Contact form demo
- order.html — Order form + live order summary demo
- style.css — Shared responsive styling
- script.js — Navigation, active links, menu details, gallery lightbox, forms and order summary
- images/ — user-provided logo/home image + four original gallery images generated for this project

## How to run
Open `index.html` in a browser. All pages use relative links, so the folder can be opened locally without a server.

## Notes
- The address, email, menu and business details are fictional.
- No real-world person is referenced.
- The four gallery images were generated specifically for this project and cropped into individual assets.
- Google Fonts are referenced for typography. If offline, the browser falls back to system fonts.
- The contact and order forms are demo-only and do not send data or process payments.
